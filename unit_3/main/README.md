# Library Management System Using Singly Linked List
## Problem Statement 
To design and implement a Library Management System in C++ using a Singly Linked List to maintain book records dynamically. The system should support insertion of books at the beginning and end, deletion of book records using Book ID, searching for a particular book, and displaying all available book records. The project aims to demonstrate the practical application of linked lists and dynamic memory allocation in managing library records efficiently.
## Approach
The project uses a Singly Linked List to store and manage library book records dynamically. Each node contains the Book ID, Book Name, Author Name, and a pointer to the next node. A head pointer is used to access the first node of the list.
The program follows a menu-driven approach that allows the user to perform different operations. Insertion at the beginning adds a new node before the current first node, while insertion at the end adds a new node after the last node. Deletion searches for a book using its ID and removes the corresponding node. Searching traverses the list to find a particular book and display its details. The display operation traverses the entire list and shows all available book records. The program continues executing until the user selects the Exit option.
## Complexity Analysis


The time complexity of the Library Management System depends on the number of book records stored in the Singly Linked List. Let **n** represent the total number of books. Insertion at the beginning takes **O(1)** time because the new node is directly linked to the head node. Insertion at the end takes **O(n)** time because the list must be traversed to reach the last node. Deletion of a book takes **O(n)** time in the worst case because the program may need to search for the specified Book ID before deleting the node. Searching for a book also takes **O(n)** time because each node may need to be checked until the required book is found. Displaying all book records takes **O(n)** time because every node in the linked list is visited.

The **space complexity is O(n)** because each book record is stored in a dynamically allocated node containing the Book ID, Book Name, Author Name, and a pointer to the next node. Therefore, the memory requirement increases linearly with the number of books. Overall, the Singly Linked List provides efficient insertion at the beginning and supports dynamic memory allocation, while operations requiring traversal have linear time complexity.
## Conclusion
The Library Management System was successfully implemented in C++ using a Singly Linked List to manage book records dynamically. The system performs essential operations such as inserting books at the beginning and end, deleting book records, searching for a book using its ID, and displaying all available books. This project helped in understanding the practical implementation of linked lists, dynamic memory allocation, and pointer manipulation. It demonstrates how data structures can be used to organize and manage records efficiently.
