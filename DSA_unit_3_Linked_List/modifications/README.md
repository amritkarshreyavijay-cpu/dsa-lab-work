# Book Recommendation System
## Problem Statement
To design and implement a Book Recommendation System in C++ using a Dynamic Singly Linked List to store and manage book records. The system should allow users to add books dynamically, search for books, display available books, and receive recommendations based on their preferred genre. Dynamic memory allocation is used to create nodes as required, allowing the system to manage a flexible number of book records without a fixed-size limit.
## Approach
The system uses a Dynamic Singly Linked List in which each book is represented by a node created dynamically using memory allocation. Each node stores the Book ID, Book Name, Author Name, Genre, and a pointer to the next node. The head pointer points to the first node in the list. Whenever a new book is added, memory is allocated for a new node and the node is linked to the existing list. The user can display all available books, search for a particular book, and enter a preferred genre to receive recommendations. For recommendations, the program traverses the linked list and displays all books whose genre matches the user's preference. If no matching books are found, an appropriate message is displayed. This approach allows the book collection to grow or shrink dynamically according to the operations performed.
## Complexity Analysis
Let **n** represent the total number of books stored in the Dynamic Singly Linked List. Insertion at the beginning takes **O(1)** time because the new node is linked directly to the head. Insertion at the end takes **O(n)** time when the list must be traversed to reach the last node. Searching for a book takes **O(n)** time in the worst case because each node may need to be checked. Displaying all books takes **O(n)** time because every node is visited. Book recommendation based on genre also takes **O(n)** time because the complete list must be traversed to find all matching books. The space complexity is **O(n)** because each book requires a dynamically allocated node. Therefore, the Dynamic Singly Linked List provides flexible memory usage and supports book management without requiring a fixed number of records.
## Conclusion
The Book Recommendation System was designed using a Dynamic Singly Linked List in C++. It allows users to store book records dynamically, search for books, display available books, and receive recommendations based on their preferred genre. The use of dynamic memory allocation provides flexibility to add books without a fixed-size limit. This project helps in understanding linked list operations, pointers, dynamic memory management, and the practical application of data structures in developing a simple book recommendation system.
