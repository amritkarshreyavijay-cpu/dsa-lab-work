## Algorithm

1. Start the program.
2. Accept the number of airports from the user.
3. Accept the names of all airports.
4. Create an adjacency list to represent the directed graph.
5. Accept the number of direct flights.
6. For each flight, accept the source and destination airport numbers and add the destination to the source airport's adjacency list.
7. Display all outgoing flights from each airport using the adjacency list.
8. Accept the airport number selected by the user.
9. Check whether the selected airport number is valid.
10. If valid, display all airports reachable through direct outgoing flights from the selected airport.
11. If the selected airport has no outgoing flights, display an appropriate message.
12. If the airport number is invalid, display an error message.
13. Stop the program.
